# 🌐 Esami di Progettazione Web (080II)

Soluzioni personali agli esami dell'insegnamento di **Progettazione Web (080II)** del Corso di Laurea in Ingegneria Informatica presso l'**Università di Pisa**.

Gli esami sono consultabili dalla pagina web [pweb.stefanobrogi.it](https://pweb.stefanobrogi.it).

---

## ⚠️ Disclaimer
Le soluzioni presenti in questa repository sono state sviluppate personalmente a scopo di esercitazione e preparazione all'esame. **Non sono soluzioni ufficiali** fornite dai docenti e potrebbero contenere imprecisioni o approcci alternativi rispetto a quelli richiesti in sede d'esame. Per le soluzioni ufficiali è possibile visitare direttamente la [repository GitHub](https://github.com/alessiovecchio/PWEB) fornita dal prof. Alessio Vecchio.

---

## 📁 Struttura della Repository

Ogni cartella corrisponde a un appello d'esame (in formato `AAAA-MM-GG`) e contiene la soluzione (`index.html`) e la traccia d'esame (`testo.pdf`).

Nella root è inoltre presente un [`index.html`](./index.html) che funge da indice navigabile per testare direttamente le varie soluzioni dal browser tramite GitHub Pages.
